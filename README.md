# 量化竞价网使用指南

[量化竞价网官网](https://www.jingjiaquant.com/) · [功能介绍](https://www.jingjiaquant.com/about) · [使用手册](https://www.jingjiaquant.com/static/strategy-help.html)

量化竞价网是面向 A 股集合竞价数据查看、市场状态观察和量化策略研究的网站。本仓库提供公开功能说明与访问入口。

## 可以查看什么

- 集合竞价：竞价总览、竞价 Top3、行业及抢筹数据、模型盘后复盘。
- 盯盘数据：市场温度、主要指数、情绪结构、涨停结构、人气新高、爆量新高、百日新高行业分布与个股明细。
- 策略结果：竞价、趋势、短线策略的每日模型结果和历史复盘，具体内容以网站当前栏目为准。
- 个股 K 线：在支持点击的股票名单中查看近三个月日 K 线。

## 从哪里开始

1. [公开盯盘数据](https://www.jingjiaquant.com/static/featured.html#review)：游客也能访问，先确认交易日期和更新时间。
2. [竞价数据](https://www.jingjiaquant.com/static/featured.html#auction)：观察高低开分布、行业与抢筹结构。
3. [使用手册](https://www.jingjiaquant.com/static/strategy-help.html)：查看各类策略的使用方式和具体规则。

## 阅读结果时需要区分

正式候选与仅观察名单有不同状态；仅观察名单不是正式入选。历史补采数据会保留“补采重算”或历史回放标记，不作为当时已经发布的前向预测。部分策略详情需要登录或相应访问权限。历史研究表现不保证未来收益。
